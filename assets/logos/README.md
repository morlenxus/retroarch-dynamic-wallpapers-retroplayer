# Platform logo artwork

These SVGs reproduce the original SEGA platform logo designs and are imported as
separate image layers in the Game Gear and Sega CD XCFs. The downloaded SVGs are
kept unchanged; the wallpaper updater scales them proportionally to fit the header.

| --- | --- | --- |
| [Sega - Game Gear.svg](Sega%20-%20Game%20Gear.svg) | [Game Gear European logo](https://commons.wikimedia.org/wiki/File:Game_gear_eu_logo.svg) | SEGA; vector sourced from Brands of the World, via Wikimedia Commons. |
| [Sega - CD.svg](Sega%20-%20CD.svg) | [Sega CD USA logo](https://commons.wikimedia.org/wiki/File:Sega_CD_Logo_(USA).svg) | SEGA design; vector redraw by Dan Patrick (JustDanPatrick), based on high-resolution scans, via Wikimedia Commons. |

Both source pages identify the artwork as public-domain text logos. SEGA and the
platform logos remain trademarks of their respective owner.
